SKILL.md ジェネレーター

Fable 5.1 専用

質問に答えるか、作りたいものをそのまま書くだけ。
Claude Code にそのまま貼れる SKILL.md 一式ができます。

  1. 書く質問に答えるか、作りたいものをそのまま書く
  2. 作るボタンを押すと裏で Claude が下書きします
  3. 置くコピーして .claude/skills/ に置けば完了
